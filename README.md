## ✨ Funcionalidades

- 🌌 **Visual galáxia** com névoas animadas e campo de estrelas
- ⚡ **Animações suaves** com Framer Motion em todos os elementos
- 📱 **Totalmente responsivo** — mobile, tablet e desktop
- 🎨 **Design glassmorphism** com efeitos de blur e transparência
- 📄 **Download e visualização** do currículo em PDF
- 🔗 **Links diretos** para GitHub e LinkedIn

## 🚀 Rodando Localmente

**Pré-requisitos:** Node.js 18+ e npm

```bash
# 1. Clone o repositório
git clone https://github.com/ThiagoRDuarte/portifolio-thiago.ramos.git

# 2. Entre na pasta
cd portifolio-thiago.ramos

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
